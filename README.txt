CARL JAVE OLIVA - PORTFOLIO WEBSITE
===================================

FILES
  index.html        the page
  css/style.css     the design
  js/script.js      the menu, dark mode, animations, contact form
  assets/img/       your project screenshots
  assets/icons/     the tech logos
  assets/favicon.svg  the small icon on the browser tab

BEFORE YOU UPLOAD (2 small steps)
  1. Open js/script.js. At the top, change the email to your real email.
     You can also add your GitHub link there.
  2. Add your photo: save it as  assets/img/photo.jpg
     (a square photo of your face works best). It shows up by itself.

HOW TO PUT IT ONLINE
  Option A - Free hosting like InfinityFree (same type as your other sites):
    Log in, open File Manager, go to the "htdocs" folder,
    and upload ALL the files and folders. Keep the same folder names.
    Open your domain. index.html loads first.

  Option B - GitHub Pages or Netlify (also free):
    GitHub Pages: make a repository, upload the files, then turn on Pages in Settings.
    Netlify: drag and drop the whole folder at app.netlify.com/drop.

TEST FIRST
  Double-click index.html. It opens in your browser, no server needed.

TIP
  Use lowercase file names. Some hosts treat "Photo.JPG" and "photo.jpg" as different files.
